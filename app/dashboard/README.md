# Dashboard Page

## Access
- URL: `http://localhost:3000/dashboard`
- This page is only accessible after signing in
- Not linked from the main landing page or login pages

## Features
- Welcome banner with personalized greeting
- Navigation tabs: Home, Scan, Notification, Profile
- Recent scans list showing:
  - Furniture item name
  - Condition status
  - Time since last scan
  - Quick access arrow

## Design
- Matches the WoodWise brand colors (#8B7355, #FFF7EC)
- Responsive design for mobile and desktop
- Clean, modern interface
- Hover effects on interactive elements

## Navigation Flow
1. User visits `/signin`
2. User enters credentials and submits
3. User is redirected to `/dashboard`
4. Dashboard displays personalized content
